# Book Store API

REST API для управления книжным интернет-магазином. Проект разработан на Python с использованием FastAPI и SQLAlchemy ORM.

## Технологии

- Python 3.12
- FastAPI — создание REST API
- SQLAlchemy ORM — работа с базой данных
- SQLite — хранение данных
- Pydantic — проверка и сериализация данных
- Uvicorn — запуск сервера

## Функциональность

### 1. Управление книгами (Books)
- Создание книги.
- Получение списка всех книг.
- Получение книги по ID.
- Обновление информации о книге.
- Удаление книги.

### 2. Управление авторами (Authors)
- Создание автора.
- Получение списка авторов.
- Получение автора по ID.
- Удаление автора.

### 3. Управление жанрами (Genres)
- Создание жанра.
- Получение списка жанров.
- Получение жанра по ID.
- Удаление жанра.

### 4. Связи между таблицами

В проекте реализованы следующие связи:

- **One-to-Many:** один автор может иметь несколько книг.
- **Many-to-One:** каждая книга принадлежит одному автору.
- **Many-to-Many:** одна книга может иметь несколько жанров, а один жанр может относиться к нескольким книгам.

Для связи книг и жанров используется промежуточная таблица `book_genres`.

### 5. Поиск и фильтрация

- Поиск книг по названию.
- Фильтрация книг по жанру.
- Одновременное использование поиска и фильтрации.

### 6. Пагинация

Поддерживается постраничное получение книг с параметрами:
- `page` — номер страницы.
- `per_page` — количество книг на странице.

## Установка и запуск

### 1. Клонирование проекта

```bash
git clone <repository-url>
cd book-store
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

Windows PowerShell:

```powershell
.venv\Scripts\activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Запуск сервера

```bash
python -m uvicorn app.main:app --reload
```

Сервер будет доступен по адресу:

http://127.0.0.1:8000

## Документация API

После запуска сервера доступны:

- Главная страница: http://127.0.0.1:8000/
- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## API Endpoints

| Метод | Endpoint | Описание |
|---|---|---|
| GET | `/books/` | Получить все книги |
| POST | `/books/` | Создать книгу |
| GET | `/books/{id}` | Получить книгу по ID |
| PUT | `/books/{id}` | Обновить книгу |
| DELETE | `/books/{id}` | Удалить книгу |
| GET | `/authors/` | Получить всех авторов |
| POST | `/authors/` | Создать автора |
| GET | `/authors/{id}` | Получить автора по ID |
| DELETE | `/authors/{id}` | Удалить автора |
| GET | `/genres/` | Получить все жанры |
| POST | `/genres/` | Создать жанр |
| GET | `/genres/{id}` | Получить жанр по ID |
| DELETE | `/genres/{id}` | Удалить жанр |

## Примеры запросов

### Получение книг с пагинацией

```http
GET /books/?page=1&per_page=10
```

### Поиск книги по названию

```http
GET /books/?search=Harry
```

### Фильтрация по жанру

```http
GET /books/?genre=Fantasy
```

### Совместный поиск и фильтрация

```http
GET /books/?search=Harry&genre=Fantasy&page=1&per_page=5
```

## Пример создания книги

```json
{
    "title": "Harry Potter",
    "description": "A young wizard begins his magical journey.",
    "price": 19.99,
    "year": 1997,
    "author_id": 1,
    "genre_ids": [1, 2]
}
```

## Тестирование

Для проверки API можно использовать Postman или встроенную документацию Swagger UI.

Проверяются:
- CRUD-операции.
- Связи между таблицами.
- Поиск по названию книги.
- Фильтрация по жанрам.
- Пагинация.
